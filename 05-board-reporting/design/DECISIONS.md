- **S4 (seasonality) is designed as the trap**, the A7-credibility analogue from churn: the storyteller is scored on de-escalating it, and a noise ledger + noise ceiling make restraint a scored property, not a hope.
- **Design doc drafted** (`design/design.md`) — status: awaiting Eva's review. Eight open questions carried in its §7.

- **N4 "structural budget optimism" added to the answer key** (only `stories.csv` changed; all public CSVs byte-identical; rules re-validated). The designed optimism bias compounds through operating leverage to ~−8% EBITDA vs budget in the story-free year — every month, a below-plan hum. Without N4, a storyteller correctly observing "you always miss budget" would have been scored a false positive; the answer key must declare everything designed.
- **Storyteller protocol** (design §5.2 realised): pinned briefing at `design/storyteller_briefing.md` — given to every run verbatim, run transcript is the audit trail; allowed inputs are the nine public CSVs + the pack and nothing else; six flag clusters enumerated (mechanical rule: every measure×grain cluster with ≥3 monthly flags in 2025, plus the single-month April EBITDA spike); a worry/stand-down verdict is mandatory per cluster, with evidence either way; findings JSON schema + one-page board memo. **Three independent runs, identical briefing, sequential; Opus** (judgment task per agent-selection rules; the model is stated honestly in the writeup).
